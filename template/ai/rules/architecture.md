# Architecture

Code lives in layers; ESLint (`boundaries/dependencies`, `project-structure/folder-structure`) rejects anything outside the matrix or the skeleton below.

## Folder skeleton (`src/`)

```
app/         App.tsx, providers/, bootstrap/, screens/<Name>Screen/
navigation/  RootNavigator.tsx AuthNavigator.tsx MainTabs.tsx linking.ts types.ts navigationRef.ts useIsSignedIn.ts
features/<kebab-name>/
  api/ components/<PascalName>/ hooks/ screens/<Name>Screen/ store/ types/ utils/ constants.ts index.ts
shared/      components/<PascalName>/  hooks/  utils/  constants/  types/
services/<kebab>/   http, storage, secure-storage, security, flags, remote-config, logger, i18n, linking, toast, network
theme/       tokens.ts themes.ts breakpoints.ts unistyles.ts scaling.ts index.ts
assets/      fonts/ images/ icons/ animations/ generated/ (generated by `yarn assets`)
locales/     en/<ns>.json  ar/<ns>.json
config/      env.ts parseEnv.ts constants.ts
test-utils/  renderWithProviders.tsx  msw/  factories/
```

- A screen folder `<Name>Screen/` must hold `<Name>Screen.tsx`, `<Name>Screen.test.tsx`, `styles.ts` and `index.ts`. It may also hold `use<Name>Screen.ts` and `use<Name>Screen.test.ts` (see "Screen logic hooks").
- A shared component folder must hold `<Name>.tsx`, `<Name>.test.tsx`, `<Name>.stories.tsx`, `styles.ts`, `types.ts` and `index.ts`, and may hold `use<Name>.ts` with `use<Name>.test.ts`.
- A feature component folder holds `<Name>.tsx`, `index.ts`, and optionally `<Name>.test.tsx`, `styles.ts`, `types.ts`, `use<Name>.ts`, `use<Name>.test.ts`.
- `services/` may nest **one** kebab-case level (`src/services/security/pinning/`). Two levels is an error.
- Unknown folders or files under `src/` are errors. Do not invent new top-level folders.

## Screen logic hooks

A screen with logic splits into a view and a hook:

- `<Name>Screen.tsx` calls `const vm = use<Name>Screen()` (or `use<Name>Screen(route)`) and renders layout only: JSX, styles, testIDs, static labels via `useTranslation`.
- `use<Name>Screen.ts` holds all logic and returns a flat view-model: values, `isX`/`hasX` booleans, `onX` handlers and logic-derived strings such as `errorMessage`. That covers `useNavigation`, `useRoute`, `useForm`, queries and mutations, `useState`/`useEffect`/`useReducer`, timers, error mapping, toasts, feature flags, store selectors and `useMemo`.
- `use<Name>Screen.test.ts` tests the hook with `renderHook`; `<Name>Screen.test.tsx` keeps the AC render tests.
- If the view-model contains a ref, destructure it out (`const { listRef, ...vm } = use<Name>Screen()`), because `react-hooks/refs` flags refs inside objects.
- Screens with only static content need no hook. Shared and feature components use `use<Name>.ts` the same way.
- Lint warns when a `*Screen.tsx` imports `react-hook-form`, `@tanstack/react-query`, `useNavigation`/`useRoute`/`useFocusEffect`, or `useState`/`useEffect`/`useReducer`.

## Path aliases

`@app/*` `@navigation/*` `@features/*` `@shared/*` `@services/*` `@theme/*` `@assets/*` `@locales/*` `@config/*` `@test-utils/*` map to the folder of the same name under `src/`.

The aliases are declared once, in `compilerOptions.paths` of `tsconfig.json`; Babel, Jest and ESLint read them from there, so adding an alias means editing that file only.

Import through an alias, never through `../` (lint error). `./` is fine inside the same folder.

## Barrels

Barrels name their exports: `export { Button } from './Button';` and `export type { ButtonProps } from './types';`. `export *` is a lint error.

An `index.ts` barrel is allowed only at: each feature root, each component/screen folder, `src/shared/components/index.ts`, `src/shared/hooks/index.ts`, `src/shared/utils/index.ts`, `src/theme/index.ts`, `src/assets/*/index.ts`.

## Boundary matrix

| From          | May import                                                                                                                                                                               |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app`         | app, navigation, shared-ui, shared-core, services, theme, assets, config, locales, a feature (**`index.ts` only**)                                                                       |
| `navigation`  | navigation, shared-ui, shared-core, services, theme, config, a feature (**`index.ts` only**)                                                                                             |
| `feature`     | its own feature (anything), another feature (**`index.ts` only**), shared-ui, shared-core, services, theme, assets, config, `navigation/types.ts` and `navigation/navigationRef.ts` only |
| `shared-ui`   | shared-ui, shared-core, services, theme, assets, config                                                                                                                                  |
| `shared-core` | shared-core, config                                                                                                                                                                      |
| `services`    | services, shared-core, config, locales                                                                                                                                                   |
| `theme`       | theme                                                                                                                                                                                    |
| `assets`      | assets                                                                                                                                                                                   |
| `locales`     | locales                                                                                                                                                                                  |
| `config`      | config                                                                                                                                                                                   |
| `test-utils`  | anything                                                                                                                                                                                 |

`shared-ui` = `src/shared/{components,hooks}`. `shared-core` = `src/shared/{utils,types,constants}` (pure code).
Only `*.test.ts(x)`, `*.stories.tsx` and `src/test-utils/**` may import `@test-utils/*`.

## Dependency ownership

Every runtime dependency in `package.json` is classified in `DEPENDENCY_POLICY` (`@rn-tempo/eslint-config`) plus the project's `dependencies` export in `eslint.config.mjs`: `owned` (only the listed folders may import it), `free` (anywhere) or `native` (no JS import expected). A new dependency needs an entry or `yarn lint:deps` (part of `yarn verify`) fails. The `rn-tempo/dependency-owner` rule reports an import from a file that does not own the package, and says where to go instead. Tests, stories, `src/test-utils/**`, `jest.setup.ts` and `__mocks__/**` are exempt.

## Restricted imports and syntax

| Import                                                                                                                           | Allowed only in                                                              |
| -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `Text`, `TouchableOpacity`, `TouchableHighlight`, `TouchableWithoutFeedback`, `Image`, `Button`, `TextInput` from `react-native` | `src/shared/components/**`                                                   |
| `StyleSheet` from `react-native`                                                                                                 | nowhere (use `react-native-unistyles`)                                       |
| `react-native-config`                                                                                                            | `src/config/env.ts` (everyone else imports `@config/env`)                    |
| `@react-native-async-storage/async-storage`                                                                                      | nowhere (use `@services/storage`)                                            |
| `axios`                                                                                                                          | `src/services/http/**`                                                       |
| `react-native-mmkv`                                                                                                              | `src/services/storage/**`                                                    |
| `react-native-keychain`                                                                                                          | `src/services/secure-storage/**` and `src/services/storage/encryptionKey.ts` |
| `react-native-svg`                                                                                                               | `src/shared/components/Icon/**` (and generated icons)                        |
| `*.svg` files                                                                                                                    | `src/shared/components/Icon/**` (draw icons with `<Icon />`)                 |

Examples of owned packages: `@react-native-community/netinfo` (`src/services/network/**`), `react-native-localize` and `react-native-restart` (`src/services/i18n/**`), `react-native-toast-message` (`src/services/toast/**`), the pickers (`src/services/files/**`). The full list is `configs/dependencies.mjs` in `@rn-tempo/eslint-config`.

Also banned, with a message that says what to use: `process.env` and `'dev' | 'staging' | 'prod'` comparisons outside `src/config/**` (use `@config/env`), color literals outside `src/theme/**`, `Appearance` and `StatusBar` outside `src/theme/**`, `src/app/**` and `Screen`, and `@test-utils/*` outside tests and stories.

Also: no default exports (`import-x/no-default-export`), no import cycles (`import-x/no-cycle`). Size guards: files up to 300 lines, at most 4 parameters, nesting depth 4. Every `eslint-disable` needs a `-- reason`, whole-file disables go at the top, and a disable that silences nothing is an error.

## Examples

```ts
// ✅ a feature talking to another feature through its public API
import { useCurrentUser } from '@features/auth';

// ❌ deep import into another feature
import { useAuthStore } from '@features/auth/store/auth.store';

// ❌ services importing UI
import { Button } from '@shared/components';

// ❌ shared code importing a feature
import { useCurrentUser } from '@features/auth';
```
