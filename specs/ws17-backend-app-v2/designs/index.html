Preview

Familiar

Open ↗

Define a scenario in the first request tab, then send to the same URL and inspect the response below.

Strength
One editor handles both sides of the request. The layout follows a familiar API-client workflow.
Trade-off
Switching from Mock to Params hides the response definition.
Best for
Developers who already work in a tabbed API client.

Studio

Open ↗

Keep the server definition and client side by side. Recent hits show when the app calls the endpoint.

Strength
Edit a scenario, try the request, and observe its traffic in one view.
Trade-off
Long payloads and URLs have less horizontal space on a laptop.
Best for
App developers iterating on error states and response shapes.

Hub

Open ↗

Start with projects and agent activity. Open a backend overview and keep its context beside the workbench.

Strength
Project state, device addresses, MCP activity, and live logs stay close at hand.
Trade-off
The overview adds a step before editing a route. The open inspector uses editor space.
Best for
Teams running several backends or supervising agent changes.
