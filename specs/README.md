# Specs

Specs for building RN-TEMPO itself. Generated projects use the same format (contract C16 in `PLAN.md`).

- [`PLAN.md`](PLAN.md): the approved implementation plan. **Read the Amendments section at the end first.**
- `ws<N>-<slug>/spec.md`: scope, owned paths, acceptance criteria and a verbatim copy of the plan section
- `ws<N>-<slug>/tasks.md`: task checklist; tick a box in the commit that completes it
- [`docs/content/docs/adr/`](../docs/content/docs/adr/index.mdx): architecture decision records (they live in the docs site)

Lifecycle: `draft` → `approved` → `in-progress` → `implemented` → `verified`.
