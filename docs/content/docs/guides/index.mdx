description: Step-by-step guides for adding an env var, translation keys and icons, and a device test matrix for releases.
---

Short, ordered guides for tasks you will repeat. Each step names the file to change and the command that proves it worked.

- [Add an env var](/docs/guides/add-env-var): schema, env files, CI secrets and docs.
- [Add translation keys](/docs/guides/add-translation-keys): namespaces, `en` and `ar`, plurals and the check.
- [Add an icon](/docs/guides/add-icon): the SVG, the registry, RTL mirroring.
- [Open phone, mail and maps](/docs/guides/open-external-links): `openPhone`, `openEmail`, `openMaps` and the Android manifest.
- [Device test matrix](/docs/guides/device-test-matrix): a table to fill in for each release.
- [Switch crash reporting provider](/docs/guides/switch-crash-reporting-provider): Crashlytics to Sentry and back, with every file and key.
- [Firebase troubleshooting](/docs/guides/firebase-troubleshooting): config files, symbols, source maps, push tokens.
