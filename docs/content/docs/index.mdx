RN Tempo is a React Native 0.88 template for teams that want strict structure from day one: three environments, enforced import boundaries, typed config, i18n with RTL, tests, CI and AI-tool support.

Start with [Getting started](/docs/getting-started), then read [Architecture](/docs/architecture) to see how the pieces fit.
