## With the CLI

```bash
npx create-tempo-app@next Demo
```

The CLI asks for the app name, bundle ID and which modules to keep (see the table below), then:

1. copies the template and renames it (`TempoApp` to your app name, `com.rntempo.app` to your bundle ID);
2. removes the modules you did not select, using the `@tempo-feature` markers and `.tempo/features/*.json` manifests ([ADR-007](/docs/adr/007-own-cli-feature-markers));
3. writes `.tempo.json`, runs `yarn install` and, on macOS, `pod install`;
4. initializes git with a first commit.

## From this repository

The `template/` folder is a runnable app with its own lockfile (it is not a workspace, see [ADR-001](/docs/adr/001-monorepo-layout)). Install the repo workspaces first, because the lint configs are linked from `packages/`:

```bash
yarn install            # repo root
cd template
yarn install
yarn pods               # macOS only
```
