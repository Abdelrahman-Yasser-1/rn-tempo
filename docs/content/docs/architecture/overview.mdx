RN Tempo is one repository with four deliverables:

| Part | Path | Role |
| --- | --- | --- |
| Template app | `template/` | React Native 0.88 app that every new project starts from |
| CLI | `packages/cli` | `create-tempo-app` and `tempo`, which generate and manage projects |
| Shared configs | `packages/{eslint-config,prettier-config,tsconfig,commitlint-config}` | Published, linked into the template with `link:` |
| Contracts | `packages/contracts` | JSON schemas and the feature-marker utilities shared by all of the above |
| Docs | `docs/` | This site |

`template/` is a standalone app with its own lockfile, not a workspace ([ADR-001](/docs/adr/001-monorepo-layout)).

Code flows downward only. The arrows are enforced by ESLint, see [Boundaries](/docs/architecture/boundaries).

## The main choices

| Area | Choice | Decision |
| --- | --- | --- |
| Client state | Zustand | [ADR-002](/docs/adr/002-zustand-tanstack-query) |
| Server state | TanStack Query | [ADR-002](/docs/adr/002-zustand-tanstack-query) |
| Styling | Unistyles 3 | [ADR-003](/docs/adr/003-unistyles) |
| Navigation | React Navigation 7, static API | [ADR-009](/docs/adr/009-static-navigation) |
| Remote config | `/app-config` endpoint | [ADR-010](/docs/adr/010-app-config-endpoint) |
| E2E | Maestro | [ADR-006](/docs/adr/006-maestro) |
| Modules | Own CLI with feature markers | [ADR-007](/docs/adr/007-own-cli-feature-markers) |
