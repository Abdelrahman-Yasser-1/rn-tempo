## Path aliases

Each top-level folder has an alias (`@app/*`, `@navigation/*`, `@features/*`, `@shared/*`, `@services/*`, `@theme/*`, `@assets/*`, `@locales/*`, `@config/*`, `@test-utils/*`). They are declared in `tsconfig.json` and mirrored in `babel.config.js`:

<AnnotatedCode file="template/tsconfig.json" highlight="5-16">
  <Note line={4}>Keep these in sync with `babel.config.js`. A mismatch builds in the editor and fails in Metro.</Note>
</AnnotatedCode>

## Naming rules

- Directories are kebab-case. Component and screen directories are PascalCase.
- `.tsx` files are PascalCase. `.ts` files are camelCase: hooks `useX.ts`, stores `x.store.ts`, API files `x.api.ts`.
- Booleans start with `is`, `has`, `should`, `can`, `did`, `will`, `show`, `hide`, and similar.
- Constants are UPPER_CASE. Enums are forbidden; use `as const` objects and union types.
- Barrels (`index.ts`) exist only at each feature root, each component or screen folder, and the shared and theme roots.
- A service folder may nest one kebab-case level (for example `src/services/security/pinning/`), not two.
