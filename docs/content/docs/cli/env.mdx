---
title: tempo env
description: List, add and remove the environments of a project.
---

```sh
tempo env list [--json]
tempo env add <name> [--display-name <text>] [--suffix .qa] [--scheme <scheme>] [--badge QA] [--skip-native] [--json]
tempo env remove <name> [--skip-native] [--yes] [--json]
```

`add` creates the Gradle flavor, the iOS build configurations and scheme, the
`package.json` scripts, an `.env.<name>` file and the launcher icons, and records
the env in `.tempo.json`. `remove` undoes all of it. The last environment cannot be
removed. `--skip-native` leaves the iOS project and the icon generator alone. On
platforms other than macOS the iOS step is skipped with a warning.

`remove` asks for confirmation unless you pass `--yes` or `--json`.

### JSON output

`list` prints `envs`. `add` and `remove` print the env that changed.

```json
{
  "ok": true,
  "envs": [
    { "name": "dev", "suffix": ".dev", "displayName": "My App Dev", "scheme": "my-app-dev", "badge": "DEV" }
  ]
}
```

```json
{
  "ok": true,
  "env": { "name": "qa", "suffix": ".qa", "displayName": "My App QA", "scheme": "my-app-qa", "badge": "QA" }
}
```

`badge` is `null` for an env without a badge. Error codes: `INVALID_ENV`,
`ENV_EXISTS`, `ENV_NOT_FOUND`, `ENV_LAST`, `GRADLE_UNPARSEABLE`,
`ICONS_SCRIPT_MISSING` and `NOT_A_TEMPO_PROJECT`.
