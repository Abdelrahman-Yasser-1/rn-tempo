## What it is

The Settings tab lists Language, Theme ([modes and palettes](/docs/features/theming)), Text size, About and Log out. Each preference is saved in MMKV and applied right away.

## Text size

**Settings > Text size** (deep link `settings/text-size`) offers four sizes:

| Size | Scale |
| --- | --- |
| Small | 0.9 |
| Default | 1.0 |
| Large | 1.15 |
| Extra large | 1.3 |

The choice is stored in MMKV `app.font-scale`. A missing or unknown value means Default. The screen has a preview line that shows the chosen size.

### How it works

- `buildTypography(userScale)` in `src/theme/themes.ts` builds every `theme.typography` variant: `fontPx(base) x userScale`, for `fontSize` and `lineHeight`.
- Picking a size calls `useAppTheme().setFontScale(scale)`. It saves the value, then calls `UnistylesRuntime.updateTheme` for each of the eight registered themes with the rebuilt typography. Every stylesheet that reads `theme.typography` updates at once; no restart.
- `initTheme()` reads `app.font-scale` and applies it before the first render, so there is no flash of the default size.
- The OS font scale still applies on top. The effective size is `base x userScale x osScale`, and the OS part is capped by `maxFontSizeMultiplier` (1.5) on `Text`, text inputs and pickers.

### Keep layouts from clipping

At Extra large with an OS scale of 1.5, text is about 1.95 times its design size. Give anything that holds text a `minHeight` or `minWidth` (never a fixed `height` or `width`), and let rows wrap. Fixed-size decorative containers, such as the avatar circle, set `maxFontSizeMultiplier={1}` on their text instead. The Storybook toolbar has a chip per size to check a component.
