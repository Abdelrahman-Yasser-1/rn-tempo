| ADR | Decision |

| [006](006-maestro.mdx) | Maestro for E2E |
| [007](007-own-cli-feature-markers.mdx) | Own CLI with feature markers |
| [008](008-ai-session-tracking.mdx) | AI session logs and commit trailers |
| [009](009-static-navigation.mdx) | React Navigation static API |
| [010](010-app-config-endpoint.mdx) | Remote config endpoint; Firebase as a recipe |
| [011](011-yarn4.mdx) | Yarn 4, node-modules linker, 24h age gate, `link:` config packages |
| [012](012-no-expo-modules.mdx) | No Expo modules |
| [013](013-babel-7.mdx) | Babel 7 until the RN preset supports 8 |

Format: Context, Decision, Consequences, Alternatives. New ADRs go in `docs/content/docs/adr/` and are added to its `meta.json`.
