- **Status:** accepted · 2026-10-24

## Decision
Use Maestro YAML flows in `e2e/flows`, driven by `testID`s (C14) and tagged with AC IDs.

## Why
- Cross-platform, low flakiness, and easy for QA to write.
- No native test harness to maintain on each RN upgrade.
- Has an MCP server for AI agents.

## Alternatives
Detox: more powerful gray-box syncing, but heavier setup and upgrade cost.
