## Skills

Project skills live in `ai/skills/` and `yarn ai:sync` copies them to `.claude/skills/`. Besides the project's own skills, the template vendors two third-party ones (React Native performance and advanced TypeScript types), pinned in `ai/skills-lock.json` and refreshed with `yarn ai:skills:update`. See [Vendored AI skills](/docs/features/ai-vendored-skills).
