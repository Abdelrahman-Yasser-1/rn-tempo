# @rn-tempo/api-contract

One Zod-typed definition per endpoint, shared by the RN-TEMPO dev API (`@rn-tempo/dev-api`), the real backend, and the generated OpenAPI, Postman and MSW outputs.

Define endpoints with `defineEndpoint`, `resource` and `defineConfig`, and check requests with `validateRequest`. Usage is documented in the docs site under Backend, Dev API.
